# IT313 Laboratory 4 - React Components and JSX

## Student Roster

This laboratory demonstrates React Native components and JSX using Expo.

## Concepts Demonstrated

- Functional Components
- Reusable Components
- Props
- Props Destructuring
- JSX Expressions
- Conditional Rendering
- Array map()
- students.length
- React list keys
- useState
- Reversing a list

## Components

### StudentCard

StudentCard is a reusable component that displays:

- Student name
- Course
- Number of units
- Full Load status

### StudentRoster

StudentRoster contains the list of students and uses map() to display each student using StudentCard.

It also displays the total number of students and provides a button for reversing the roster.
